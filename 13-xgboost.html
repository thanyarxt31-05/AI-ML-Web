XGBoost

Gradient Boosting แบบ XGBoost: ต้นไม้ตัวใหม่แก้ความผิดพลาดของตัวก่อน

Boosting ปลูกต้นไม้เล็ก ๆ ทีละต้น แต่ละต้นเรียนเฉพาะส่วนที่ทีมก่อนหน้ายังทำนายพลาด (residual) แล้วบวกเข้าไปทีละนิดตาม learning rate เลื่อนแถบรอบที่ m เพื่อดูการสะสมทีละต้น ตัวอย่างนี้เป็นการถดถอย 1 มิติให้เห็นภาพชัด

เส้นทึบดำ = ผลรวมถึงรอบ m, เส้นประเทา = ฟังก์ชันจริง, จุดกลวง = ข้อมูลทดสอบ

Residual ก่อนรอบ m และต้นไม้ที่ m ที่เรียนมันอยู่

MSE ของ train (น้ำเงิน) และ test (ชมพู) ตามจำนวนรอบ

ทำความรู้จัก

ใช้ทำอะไร: ต้นไม้เรียงต่อกัน แต่ละต้นแก้ข้อผิดพลาดของต้นก่อน

XGBoost (eXtreme Gradient Boosting) เป็นวิธี ensemble แบบ boosting ที่ต่างจาก Random Forest ตรงที่ปลูกต้นไม้ทีละต้นแบบเรียงลำดับ ต้นใหม่แต่ละต้นเรียนเฉพาะส่วนที่โมเดลรวมก่อนหน้ายังทำนายผิด (residual หรือ gradient ของ loss) แล้วบวกเข้าไปทีละน้อยตาม learning rate XGBoost เพิ่ม regularization (λ, γ) ลงในสูตรการเลือกจุดแบ่งและค่าของใบ ใช้ข้อมูลทั้ง gradient และ hessian และมีการปรับแต่งด้านความเร็วมาก จึงเป็นโมเดลที่ชนะการแข่งขัน Kaggle บนข้อมูลตารางบ่อยที่สุด ทางเลือกที่คล้ายกันคือ LightGBM และ CatBoost

ตัวอย่างการใช้งานจริง

  • ทำนายความเสี่ยงสินเชื่อและตรวจจับการฉ้อโกง
  • จัดอันดับผลการค้นหาและโฆษณา (learning to rank)
  • ทำนายยอดขายและความต้องการสินค้า
  • งานแข่งขันข้อมูลตารางแทบทุกประเภท

จุดเด่น

  • แม่นยำสูงมากบนข้อมูลตาราง
  • มี regularization ในตัว และจัดการค่าที่หายไปได้เอง
  • เร็ว รองรับการประมวลผลขนานและ GPU

ข้อจำกัด

  • มีพารามิเตอร์ให้จูนหลายตัว
  • Overfit ได้ถ้ารอบมากเกินหรือ learning rate สูงเกิน ต้องใช้ early stopping
  • ไวต่อข้อมูลที่มี noise มากกว่า Random Forest

พารามิเตอร์สำคัญ

n_estimators
จำนวนรอบ ใช้คู่กับ early stopping
learning_rate (η)
ค่าน้อยแม่นกว่าแต่ต้องใช้รอบมากขึ้น

ความลึกของต้นไม้แต่ละต้น มักใช้ 3 ถึง 8

ตัวควบคุมความซับซ้อนและ overfitting

ควรเลือกใช้เมื่อไร

เลือกใช้เมื่อต้องการความแม่นยำสูงสุดบนข้อมูลตาราง และมีเวลาจูนพารามิเตอร์

ทำงานอย่างไร

  1. เริ่มทำนายด้วยค่าเฉลี่ยของ y ทุกจุด
  2. คำนวณ gradient gᵢ = ŷᵢ − yᵢ ของแต่ละจุด (สำหรับ squared loss คือ residual กลับเครื่องหมาย) และ hessian hᵢ = 1
  3. ปลูกต้นไม้เล็ก โดยเลือกเส้นแบ่งที่ให้ gain สูงสุด ตามสูตรของ XGBoost ซึ่งมี λ และ γ คอยกันไม่ให้ซับซ้อนเกิน
  4. ค่าของแต่ละใบคือ −G/(H+λ) แล้วคูณด้วย η ก่อนบวกเข้าโมเดลรวม
  5. ทำซ้ำหลายรอบ ดูกราฟ test MSE ถ้ารอบมากเกินหรือ η สูงเกิน test จะเริ่มแย่ลง (overfit)

สมการหลัก

ŷ⁽ᵐ⁾(x) = ŷ⁽ᵐ⁻¹⁾(x) + η · f_m(x) gᵢ = ŷᵢ − yᵢ , hᵢ = 1 w_leaf = −G / (H + λ) Gain = ½ [ G_L²/(H_L+λ) + G_R²/(H_R+λ) − G²/(H+λ) ] − γ

XGBoost ตัวจริงมีอีกหลายอย่าง เช่น หาจุดแบ่งด้วย histogram, จัดการค่าหาย และรันขนาน แต่แกนกลางคือสูตร gain และค่าใบด้านบนนี้
