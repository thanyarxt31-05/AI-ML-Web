การถดถอยเชิงเส้น: ลากเส้นที่ใกล้จุดข้อมูลทุกจุดที่สุด

ดูโมเดลค่อย ๆ ปรับน้ำหนักด้วย Gradient Descent จนเส้นทำนายลดระยะห่างกำลังสองกับข้อมูลให้น้อยที่สุด ลองเพิ่มดีกรีพหุนามเพื่อดูเส้นโค้ง หรือเพิ่ม learning rate จนโมเดลแกว่ง

คลิกเพื่อเพิ่มจุด, Shift+คลิกเพื่อลบจุดที่ใกล้ที่สุด

Loss (MSE) ระหว่างฝึก

Residual ของแต่ละจุด (เรียงตาม x)

ข้อมูล
โมเดล

ทำงานอย่างไร

  1. เริ่มจากน้ำหนัก w เป็นศูนย์ เส้นทำนายจึงนอนราบ
  2. คำนวณค่าทำนาย ŷ ของทุกจุด แล้ววัดความผิดพลาดด้วย MSE (ค่าเฉลี่ยของ residual ยกกำลังสอง)
  3. หาความชัน (gradient) ของ MSE เทียบกับน้ำหนักแต่ละตัว
  4. ขยับน้ำหนักไปทางตรงข้ามกับ gradient เป็นระยะเท่ากับ learning rate
  5. ทำซ้ำจน loss แทบไม่ลดลงอีก ถ้า learning rate ใหญ่เกินไป loss จะพุ่งขึ้นแทน
