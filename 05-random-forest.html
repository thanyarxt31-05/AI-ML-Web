Random Forest

ป่าสุ่ม: ต้นไม้หลายต้นช่วยกันโหวต

ต้นไม้ต้นเดียวมักจำข้อมูลมากเกินไป Random Forest จึงปลูกต้นไม้หลายต้น แต่ละต้นเห็นข้อมูลที่สุ่มมาไม่เหมือนกัน แล้วเอาคำตอบมาเฉลี่ย ภาพเล็กด้านล่างคือต้นไม้ 6 ต้นแรก สังเกตว่าแต่ละต้นแปลก ๆ แต่ผลรวมเรียบกว่า

สีเข้มคือต้นไม้ส่วนใหญ่เห็นตรงกัน สีอ่อนคือโหวตสูสี

ต้นไม้แต่ละต้น (6 ต้นแรก) ฝึกจากข้อมูลคนละชุด

ความแม่นยำบนข้อมูลทดสอบ เมื่อเพิ่มจำนวนต้นไม้

ทำความรู้จัก

ใช้ทำอะไร: รวมต้นไม้หลายต้นให้แม่นและเสถียรขึ้น

Random Forest เป็นวิธี ensemble แบบ bagging ที่ปลูกต้นไม้ตัดสินใจหลายร้อยต้น แต่ละต้นฝึกจากข้อมูลที่สุ่มแบบใส่คืน (bootstrap) และทุกครั้งที่แบ่งจะเลือกจากฟีเจอร์ที่สุ่มมาเพียงบางส่วน ต้นไม้แต่ละต้น overfit คนละแบบ เมื่อนำมาโหวตรวมกัน ความผิดพลาดแบบสุ่มจะหักล้างกัน ได้โมเดลที่แม่นยำและเสถียรกว่าต้นไม้ต้นเดียวมาก เป็นหนึ่งในโมเดลที่ใช้ได้ดีทันทีโดยแทบไม่ต้องปรับค่า

ตัวอย่างการใช้งานจริง

  • ตรวจจับธุรกรรมฉ้อโกง
  • จำแนกการใช้ที่ดินจากภาพถ่ายดาวเทียม
  • จัดอันดับความสำคัญของฟีเจอร์ (feature importance)
  • งานข้อมูลตาราง (tabular) ทั่วไป

จุดเด่น

  • แม่นยำสูงโดยไม่ต้องปรับพารามิเตอร์มาก
  • Overfit ยากกว่าต้นไม้เดี่ยว เพิ่มจำนวนต้นแล้วไม่แย่ลง
  • มีค่า out-of-bag ใช้ประเมินผลได้โดยไม่ต้องแยก test set

ข้อจำกัด

  • อธิบายยากกว่าต้นไม้ต้นเดียว
  • ใช้หน่วยความจำและเวลาทำนายมากขึ้นตามจำนวนต้น
  • มักแพ้ gradient boosting เล็กน้อยในงานแข่งขัน

พารามิเตอร์สำคัญ

n_estimators
จำนวนต้นไม้ ยิ่งมากยิ่งเสถียร แต่ช้าลง
max_features
จำนวนฟีเจอร์ที่สุ่มให้เลือกแต่ละครั้ง ตัวสร้างความหลากหลายของต้นไม้
max_depth
ความลึกของแต่ละต้น
bootstrap
สุ่มข้อมูลแบบใส่คืนหรือไม่

ควรเลือกใช้เมื่อไร

เลือกใช้เป็นโมเดลมาตรฐานสำหรับข้อมูลตาราง เมื่ออยากได้ผลดีเร็ว ๆ โดยไม่ต้องจูนมาก

ทำงานอย่างไร

  1. สุ่มข้อมูลฝึกแบบใส่คืน (bootstrap) ให้แต่ละต้นได้ชุดข้อมูลขนาดเท่าเดิมแต่ซ้ำ ๆ ขาด ๆ
  2. ปลูกต้นไม้แต่ละต้น โดยทุกครั้งที่แบ่งให้เลือกจากฟีเจอร์ที่สุ่มมาเพียงบางส่วน
  3. ความสุ่มสองชั้นนี้ทำให้ต้นไม้ผิดพลาดคนละแบบ จึงหักล้างกันเมื่อนำมารวม
  4. ทำนายโดยให้ทุกต้นโหวต หรือเฉลี่ยความน่าจะเป็น
  5. จุดที่ต้นไม้ไม่ได้สุ่มไปใช้ (out-of-bag) ใช้ประเมินความแม่นยำได้ฟรีโดยไม่ต้องแยก test
