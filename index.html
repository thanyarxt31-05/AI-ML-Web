ML Visual Lab

ห้องทดลองอัลกอริทึม Machine Learning 14 แบบ ทุกหน้าคำนวณจริงในเบราว์เซอร์ ปรับตัวเลขแล้วดูโมเดลเปลี่ยนตามทันที ไม่ต้องติดตั้งอะไร

Supervised learning

เรียนจากข้อมูลที่มีคำตอบกำกับ

1Linear Regressionการถดถอยเชิงเส้น: ลากเส้นที่ใกล้จุดข้อมูลทุกจุดที่สุด2Logistic Regressionการถดถอยโลจิสติก: ทำนายความน่าจะเป็นของคลาส3k-Nearest Neighborsเพื่อนบ้านใกล้ที่สุด k ตัว: ดูว่าคนรอบข้างเป็นใคร4Decision Treeต้นไม้ตัดสินใจ: ถามคำถามใช่/ไม่ใช่ ทีละข้อ5Random Forestป่าสุ่ม: ต้นไม้หลายต้นช่วยกันโหวต6Support Vector Machineซัพพอร์ตเวกเตอร์แมชชีน: หาเส้นแบ่งที่เว้นระยะห่างกว้างที่สุด

Unsupervised learning

หาโครงสร้างในข้อมูลที่ไม่มีคำตอบ

7K-Meansการจัดกลุ่มแบบ K-Means: แบ่งข้อมูลเป็น K กลุ่มโดยไม่มีเฉลย

Deep learning

โครงข่ายประสาทเทียม (ส่วนใหญ่ฝึกแบบ supervised)

8MLP Neural Networkโครงข่ายประสาทเทียมหลายชั้น: ซ้อนเส้นตรงหลายเส้นจนได้รูปร่างอะไรก็ได้9CNNโครงข่ายคอนโวลูชัน: เลื่อนตัวกรองเล็ก ๆ ไปทั่วภาพเพื่อหาลวดลาย10LSTMหน่วยความจำระยะสั้นแบบยาว: เซลล์ที่เลือกได้ว่าจะจำหรือลืม11Transformerทรานส์ฟอร์เมอร์: ให้ทุกคำมองหาคำอื่นที่เกี่ยวข้องผ่าน self-attention

Reinforcement learning

เรียนจากรางวัลที่ได้เมื่อลงมือทำ

12Reinforcement Learningการเรียนรู้แบบเสริมกำลัง (Q-Learning): ลองผิดลองถูกเพื่อเก็บรางวัลให้มากที่สุด

Ensemble (ถ้ามีเวลา)

รวมหลายโมเดลให้เก่งกว่าตัวเดียว

13XGBoostGradient Boosting แบบ XGBoost: ต้นไม้ตัวใหม่แก้ความผิดพลาดของตัวก่อน14StackingStacking: ให้โมเดลอีกตัวเรียนว่าควรเชื่อโมเดลไหนมากแค่ไหน
