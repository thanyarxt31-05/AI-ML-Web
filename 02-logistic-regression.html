Logistic Regression

การถดถอยโลจิสติก: ทำนายความน่าจะเป็นของคลาส

โมเดลเชิงเส้นที่บีบผลลัพธ์ผ่านฟังก์ชัน sigmoid ให้อยู่ระหว่าง 0 ถึง 1 สีพื้นหลังคือความน่าจะเป็นที่จะเป็นคลาส B เส้นทึบคือเส้นแบ่ง (decision boundary) ลองเปิดฟีเจอร์กำลังสองเพื่อให้เส้นโค้งได้

คลิกเพื่อเพิ่มจุดของคลาสที่เลือกไว้

Log-loss ระหว่างฝึก

Sigmoid: แต่ละจุดอยู่ตรงไหนบนเส้นโค้ง

ข้อมูล
โมเดล

ทำงานอย่างไร

  1. รวมฟีเจอร์ของแต่ละจุดเป็นคะแนน z = w·x + b (เป็นเส้นตรงในระนาบ)
  2. ส่ง z เข้า sigmoid ได้ความน่าจะเป็น p ว่าเป็นคลาส B
  3. วัดความผิดพลาดด้วย log-loss ซึ่งลงโทษหนักเมื่อโมเดลมั่นใจแต่ผิด
  4. อัปเดตน้ำหนักด้วย gradient descent โดย gradient มีรูปง่าย ๆ คือ (p − y)·x
  5. ตัดสินคลาสเมื่อ p เกิน threshold ขยับ threshold แล้วดูเส้นแบ่งเลื่อนตาม

สมการหลัก

z = w₀ + w₁x + w₂y (+ w₃x² + w₄y² + w₅xy) p = σ(z) = 1 / (1 + e^(−z)) Loss = −(1/n) Σ [yᵢ log pᵢ + (1−yᵢ) log(1−pᵢ)] + (λ/2) ‖w‖² ∂Loss/∂w = (1/n) Σ (pᵢ − yᵢ) xᵢ + λw

ชุดข้อมูล XOR และวงกลมซ้อนแบ่งด้วยเส้นตรงไม่ได้ ถ้าเปิดฟีเจอร์กำลังสอง โมเดลเดิมก็แบ่งได้ทันที
