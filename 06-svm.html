Support Vector Machine

ซัพพอร์ตเวกเตอร์แมชชีน: หาเส้นแบ่งที่เว้นระยะห่างกว้างที่สุด

SVM ไม่ได้หาเส้นแบ่งเส้นไหนก็ได้ แต่หาเส้นที่มีถนน (margin) กว้างที่สุดระหว่างสองคลาส จุดที่อยู่บนขอบถนนหรือล้ำเข้ามาเรียกว่า support vector (วงดำ) มีแค่จุดเหล่านี้ที่กำหนดเส้นแบ่ง ลองลากเพิ่มจุดไกล ๆ แล้วดูว่าเส้นไม่ขยับเลย

เส้นทึบ f(x)=0, เส้นประ f(x)=±1, คลิกเพื่อเพิ่มจุด

ค่า α ของแต่ละจุด (จุดที่ α > 0 คือ support vector, ชนเพดาน C คือจุดที่ล้ำ margin)

ทำความรู้จัก

ใช้ทำอะไร: หาเส้นแบ่งที่มี margin กว้างที่สุด

Support Vector Machine หาเส้นแบ่ง (hyperplane) ที่เว้นระยะห่างจากจุดที่ใกล้ที่สุดของแต่ละคลาสให้มากที่สุด จุดที่อยู่บนขอบ margin เรียกว่า support vector และมีเพียงจุดเหล่านี้ที่กำหนดเส้นแบ่ง ด้วยเทคนิค kernel trick SVM วัดความคล้ายในมิติที่สูงขึ้นได้โดยไม่ต้องคำนวณมิตินั้นจริง จึงสร้างเส้นแบ่งโค้งได้ ค่า C ใช้ควบคุมว่าจะยอมให้จุดล้ำ margin ได้มากแค่ไหน (soft margin)

ตัวอย่างการใช้งานจริง

  • จำแนกข้อความและวิเคราะห์ความรู้สึก (sentiment)
  • จำแนกโปรตีนและยีนในชีวสารสนเทศ
  • ตรวจจับใบหน้าในภาพ (งานยุคก่อน deep learning)
  • งานที่ข้อมูลน้อยแต่มีฟีเจอร์มาก

จุดเด่น

  • ทำงานดีในมิติสูง แม้จำนวนฟีเจอร์มากกว่าจำนวนข้อมูล
  • ใช้แค่ support vector ในการทำนาย
  • มีฐานทฤษฎีแน่น ปัญหาการฝึกเป็น convex จึงได้คำตอบที่ดีที่สุดเสมอ

ข้อจำกัด

  • ฝึกช้าเมื่อข้อมูลเกินหลักหมื่นถึงแสน เพราะต้องคำนวณ kernel ทุกคู่
  • ต้องปรับสเกลข้อมูลและจูน C กับ γ ให้ดี
  • ไม่ให้ความน่าจะเป็นโดยตรง

พารามิเตอร์สำคัญ

C
ค่าปรับเมื่อจุดล้ำ margin สูง = เข้มงวด เสี่ยง overfit
kernel
Linear, RBF, Polynomial เลือกรูปร่างของเส้นแบ่ง
γ (gamma)
รัศมีอิทธิพลของแต่ละจุดใน RBF สูงไปจะเป็นเกาะเล็ก ๆ

ควรเลือกใช้เมื่อไร

เลือกใช้เมื่อข้อมูลขนาดเล็กถึงกลาง มีมิติสูง และต้องการเส้นแบ่งที่ทนทาน

ทำงานอย่างไร

  1. แปลงคลาสเป็น −1 และ +1 แล้วมองหาฟังก์ชัน f(x) ที่ให้ค่าบวกกับคลาส +1 และลบกับคลาส −1
  2. บังคับให้จุดทุกจุดอยู่นอกถนน |f(x)| ≥ 1 และทำให้ถนนกว้าง 2/‖w‖ มากที่สุด
  3. ถ้าข้อมูลแยกไม่ขาด ยอมให้บางจุดล้ำถนนได้ แต่จ่ายค่าปรับตามค่า C (C น้อยถนนกว้างแต่ยอมผิดง่าย)
  4. แก้ปัญหาในรูป dual ด้วยอัลกอริทึม SMO ซึ่งปรับค่า α ทีละคู่
  5. Kernel ช่วยวัดความคล้ายในมิติที่สูงขึ้นโดยไม่ต้องคำนวณมิตินั้นจริง เส้นแบ่งจึงโค้งได้

สมการหลัก

f(x) = Σᵢ αᵢ yᵢ K(xᵢ, x) + b max Σαᵢ − ½ ΣΣ αᵢαⱼ yᵢyⱼ K(xᵢ,xⱼ) s.t. 0 ≤ αᵢ ≤ C, Σ αᵢyᵢ = 0 Linear: K = xᵢ·xⱼ RBF: K = exp(−γ‖xᵢ − xⱼ‖²) Poly: K = (xᵢ·xⱼ + 1)^d

RBF ที่ γ สูงมาก จะสร้างเกาะเล็ก ๆ รอบแต่ละจุด เป็นอีกรูปแบบหนึ่งของ overfitting
