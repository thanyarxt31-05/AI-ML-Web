Reinforcement Learning

การเรียนรู้แบบเสริมกำลัง (Q-Learning): ลองผิดลองถูกเพื่อเก็บรางวัลให้มากที่สุด

ตัวแทน (จุดสีเหลือง) ไม่รู้แผนที่เลย มันเดินสุ่ม ได้รางวัลเมื่อถึงธงเขียว และถูกลงโทษเมื่อตกหลุมสีชมพู ทุกก้าวมันอัปเดตตาราง Q ที่บอกว่าแต่ละทางในแต่ละช่องดีแค่ไหน สีพื้นและลูกศรคือสิ่งที่มันเรียนรู้ได้ ลองวาดกำแพงหรือหลุมเพิ่มระหว่างฝึก

คลิกหรือลากบนตารางเพื่อวางสิ่งที่เลือกในเครื่องมือแก้ไขแผนที่

ผลรวมรางวัลต่อรอบ (episode) และค่าเฉลี่ยเคลื่อนที่ 20 รอบ

แก้ไขแผนที่
Q-Learning
การแสดงผล

ทำงานอย่างไร

  1. สถานะ s คือช่องที่ตัวแทนยืน การกระทำ a คือเดินขึ้น ขวา ลง ซ้าย
  2. เลือกการกระทำแบบ ε-greedy: ส่วนใหญ่เลือกทางที่ Q สูงสุด แต่บางครั้ง (ε) สุ่มเพื่อสำรวจ
  3. เดินหนึ่งก้าว ได้รางวัล r และสถานะใหม่ s′
  4. อัปเดต Q(s,a) ให้เข้าใกล้ r + γ·max Q(s′,·) ซึ่งเป็นการประเมินที่ดีกว่าเดิมเล็กน้อย
  5. เมื่อถึงเป้าหมายหรือหลุม เริ่มรอบใหม่ หลายพันก้าวต่อมา ลูกศรจะชี้ทางที่ดีที่สุดจากทุกช่อง

สมการหลัก

Q(s,a) ← Q(s,a) + α [ r + γ max_a′ Q(s′,a′) − Q(s,a) ] π(s) = argmax_a Q(s,a) (ทำตามนโยบาย) สุ่ม a ด้วยโอกาส ε (สำรวจ) V(s) = max_a Q(s,a) ← สีของแต่ละช่อง

ลองแผนที่หน้าผากับ ε สูง: Q-Learning จะเรียนเส้นทางเลียบขอบหลุมที่สั้นที่สุด แม้ระหว่างฝึกจะตกบ่อยก็ตาม
